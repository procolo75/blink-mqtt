Live View clips — what these settings apply to

These settings apply only to sync modules in Live View mode: no USB storage and no Blink subscription. Blink saves nothing for them, so the app records the clip itself from Live View and publishes it on event/clip (JARVIS → Telegram).

Sync modules with USB storage (or a subscription) are never touched by anything on this page. The camera records its own clip from the very moment of motion and the app forwards it as before — better than any Live View clip. Nothing here starts, stops or changes their recordings.
What starts a clip automatically on motion

The Record clip button works in every mode: it is a manual command (record/trigger), not a motion trigger.

Timing

Used only by Blink polling and Both, and only while a Live View module is armed. Lower = reacts sooner, more requests. 5 is the minimum.

Every second of Live View keeps the camera awake: longer clips cost more battery.

Why the clip starts after the motion. Delay = time to learn about the motion (polling interval, or Alexa) + about 5 s for Blink to open Live View. A Live View clip therefore shows what happens after the motion, never the moment itself. Only a module with USB storage records that moment.
Alexa setup — needed for “Alexa / external” and “Both”
  1. Link Blink to Alexa: Alexa app → More → Skills & Games → Blink SmartHome → Enable → sign in with the Blink account → Discover devices.
    ⚠ Linking may start a Blink plan trial on its own. Check in the Blink app and cancel it if you don't want it: while a plan is active Blink stores cloud clips, the module switches to Cloud mode and the app forwards those clips instead (up to an hour after cancelling — restart the app to switch back at once).
  2. Create the script in Home Assistant for each camera below: Settings → Automations & scenes → Scripts → Add → ⋮ → Edit in YAML → paste → Save.
  3. Expose it to Alexa (Nabu Casa): Settings → Voice assistants → Expose → Expose entities → the script → Amazon Alexa. Then Alexa app → Devices → + → Discover devices. It appears in Alexa as a scene.
  4. Alexa routine: Alexa app → More → Routines → + → When this happens: Smart Home → the camera → Motion detected → Add action: Smart Home → Scenes → the script.
  5. Set the mode above to Alexa / external or Both.
